# Project-Parallax
A research-oriented companion dashboard and Python/Streamlit project for **Spatial AI — Monocular + Stereo Depth Fusion for 3D Scene Understanding**.

- The React application in `src/` is the polished visual companion and workflow explorer.
- The working computer-vision project is in [`spatial_ai/`](spatial_ai/), including the Streamlit dashboard, Depth Anything V2, StereoSGBM, fusion, YOLO, point clouds, calibration tools, tests, and methodology documentation.

See [`spatial_ai/README.md`](spatial_ai/README.md) for setup, technical details, evaluation protocol, and limitations.
